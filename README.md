# ПМ11 — Система учёта паспортов кабинетов информатики

## Описание проекта
Система предназначена для автоматизации учёта паспортов кабинетов информатики, оборудования и программного обеспечения, а также для организации взаимодействия между преподавателями и техническим персоналом через заявки на обслуживание.

## Технологии
- **SQL Server** — база данных
- **Visual Studio (C# / .NET)** — клиентское приложение
- **GitHub** — контроль версий

## Роли пользователей
| Роль | Количество | Права доступа |
|------|------------|---------------|
| Администратор | 1 | Полный доступ |
| Техник | 1 | Обработка заявок, редактирование паспортов АРМ |
| Преподаватель | 5 | Просмотр кабинета, создание заявок, чат |
